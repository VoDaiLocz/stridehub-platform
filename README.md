# StrideHub

StrideHub is a production-style multi-vendor footwear marketplace built as a modular monolith.

## Current Status

The repository currently contains the initial Spring Boot workspace and a detailed engineering documentation package covering:

- product requirements
- system architecture
- domain model
- architecture decision records
- API baseline
- operational runbooks
- test and release process

## Documentation

- [Documentation Index](./docs/README.md)

## Stack Direction

- Java 21
- Spring Boot
- PostgreSQL
- Redis
- Flyway
- JWT-based authentication
- OpenAPI-first REST contracts
