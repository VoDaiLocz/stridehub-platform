# Runbook Index

These runbooks are forward-looking operational guides. They should be read as
`target-state` procedures unless the corresponding capability is already implemented
in the current baseline.

- `payment-webhook-failure.md` is partially applicable in Phase 1 because signed webhook handling exists.
- `stuck-order-recovery.md` becomes more actionable as later operational tooling is added.
- `refund-mismatch-investigation.md` is mainly a Program 3 reference because refunds are not implemented in Phase 1.
